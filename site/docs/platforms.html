The tier list is a plan. The index builder decides which toolchains exist per host; jig toolchain available always reports the truth for the machine it runs on.

What each platform needs from the machine (v0.1, hermeticity H1)

PlatformPinned by jigStill from the machinePrerequisite message
Linuxcompiler, CMake, Ninjalibc (glibc or musl as the toolchain entry requires), system headers, C++ runtime unless the entry says otherwiseDJ3203 names the required glibc version
macOScompiler, CMake, NinjamacOS SDK and system librariesDJ3202: xcode-select --install
Windowscompiler (clang), CMake, NinjaMSVC runtime, Windows SDK from Visual Studio Build ToolsDJ3201: install "Desktop development with C++"

jig does not bundle the macOS SDK or the Windows SDK in v0.1 (decision D-009).

Verbose on purpose.

Every decision comes with its reason. Which compiler, why that version, what it dropped from your environment, how much of the build is pinned.

Add --explain for the reasoning tree, -vv for every command it ran, --json for events a script can read, -q when you want quiet.

// What it does

One stem. Three bars.

Pin

Compilers, CMake and Ninja come from a signed index and are checked by sha256. jig.lock records exactly what you got.

Isolate

Each project gets .jig/env. Pinned tools come first, leaking variables are dropped, and ten projects share one copy on disk.

Build

Generated CMake, Ninja, CTest and the pinned clang-format, with compile_commands.json for your editor.

// Choose before you create

The standard picks the compiler.

Say which language standard you want. jig shows only the compiler versions that accepted it when the index was built.

The index builder runs every compiler with -std=… -fsyntax-only and records the result, so the list is measured, not copied from a table.

    // Truth

    How much is pinned?
    jig tells you.

    Most “reproducible” claims quietly lean on the host’s C library and headers. jig names what it pins and what it does not, and jig doctor prints your level.

    H0
    Detected0.1
    The machine’s compiler was found and recorded. Nothing is pinned.
    H1
    Pinned compiler0.1
    Compiler, CMake and Ninja by hash. C library, system headers and platform SDK still come from the machine.
    H2
    Pinned runtime0.3
    Adds the compiler’s own C++ runtime and a sysroot where the provider ships one.
    H3
    Hermetic0.3
    Build for any target from any host.

    // Scope

    Not a build system.
    Not a package manager.

    jig is the layer above them. It generates CMake and runs Ninja, so existing projects and editors keep working.

    jigCreate the project. Pin the compiler. Isolate the environment. Run, test, format. Explain.
    CMake + NinjaDescribe and run the build. Generated by jig, or your own CMakeLists.txt via jig init --adopt.
    vcpkg · git · pathDependencies, handed off with the pinned compiler. Planned for 0.2.
    jig initCreate a project after you choose.
    jig toolchainList, install, switch, pin.
    jig lock · syncResolve, then realise the environment.
    jig build · runGenerate, configure, build, run.
    jig test · fmtCTest and the pinned clang-format.
    jig exec · shellAnything, inside the environment.
    jig doctorChecks and the hermeticity level.
    jig selfVerified update and rollback.

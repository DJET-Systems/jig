CLI reference

This sheet is the contract for the command surface. A test (T-002-02) compares it with the CLI11 command tree and fails when they differ. Entries marked (v0.2) are reserved.

Synopsis

jig [GLOBAL FLAGS] <COMMAND> [ARGS]

Global flags

FlagEnvDescription
-v, -vv, -vvvJIG_VERBOSEDetail, commands, trace.
-q, -qqJIG_QUIETTerse, errors only.
--terseJIG_TERSEOne line per step.
--explainPrint the decision tree after the output.
--jsonJIG_JSONNewline-delimited JSON events on stdout.
--color auto\always\neverJIG_COLOR, NO_COLORColour.
--offlineJIG_OFFLINENo network.
--lockedJIG_LOCKEDFail if the lock is missing or stale.
--frozenJIG_FROZEN--locked plus --offline.
--manifest-path PATHJIG_MANIFESTUse another jig.toml.
--home DIRJIG_HOMEUser data directory.
-y, --yesJIG_YESAccept defaults and confirmations.
--no-interactiveJIG_NO_INTERACTIVENever prompt.
-h, --helpHelp.
-V, --versionVersion.

jig init [PATH]

Create a project. Asks for anything not given by a flag.

OptionDescription
--name NAMEProject name (default: directory name).
--lang c\c++Language.
--std STDc11 c17 c23 or c++14 c++17 c++20 c++23 c++26.
--vendor llvm\systemCompiler vendor.
--toolchain SPECFor example clang@20, clang@20.1, clang@&gt;=18,&lt;21, clang@latest.
--compiler-firstAsk for the compiler before the standard.
--prereleaseInclude prerelease compilers.
--allow-incompatibleContinue with a compiler that does not accept the standard (warns).
--kind exe\static-lib\shared-lib\header-onlyProject kind.
--tests none\ctestTest scaffold. (catch2, doctest, gtest, unity in v0.2.)
--clang-format none\llvm\google\mozilla\webkit\file.clang-format.
--vcs git\nonegit init and .gitignore.
--license SPDXRecorded in jig.toml.
--platforms LISTHosts the lock must cover.
--template NAMEForce a template (see blueprint 006).
--adoptAdd jig.toml to an existing CMake project.
--forceWrite into a non-empty directory.
--no-install, --no-sync, --no-lockSkip steps.
--dry-runPrint decisions and file list; write nothing.
jig init hello --lang c++ --std c++23 --toolchain clang@20 -y
jig init --adopt --lang c++ --std c++20 --toolchain clang@19
jig init lib --lang c --std c17 --kind static-lib --vendor system --dry-run -y

jig toolchain

SubcommandSynopsisNotes
listjig toolchain list [--all]Installed in the store. --all includes detected system compilers.
availablejig toolchain available [--vendor V] [--lang L] [--std S] [--host TRIPLE] [--prerelease]From the index, filtered.
installjig toolchain install SPEC [--vendor V] [--host TRIPLE]Download, verify, extract.
usejig toolchain use SPECEdit jig.toml, re-lock, sync.
pinjig toolchain pin [SPEC]Write the exact version into jig.toml. Without SPEC, pins the currently locked one.
whichjig toolchain which [TOOL]Print the real path of a tool.
removejig toolchain remove SPEC [--force]Remove from the store.
updatejig toolchain updateRefresh the index; report newer patch versions.
jig toolchain available --lang c++ --std c++23
jig toolchain install clang@20
jig toolchain use clang@19.1

jig lock

jig lock [--platform HOST...] [--upgrade] [--check]. Resolve and write jig.lock. --check exits 3 if the lock would change. --platform all covers every supported host.

jig sync

jig sync [--check] [--reinstall]. Make .jig/env match the lock.

jig env

jig env [--format sh|fish|pwsh|cmd|json]. Print the environment.

eval "$(jig env)"
jig env --format pwsh | Invoke-Expression

jig shell

jig shell [--shell NAME]. Subshell with the environment.

jig exec

jig exec -- CMD [ARGS...]. Run any command inside the environment.

jig exec -- c++ --version
jig exec -- cmake --version

jig build

OptionDescription
--profile NAMEBuild profile (default debug).
--releaseSame as --profile release.
--target NAMEBuild one target.
-j N, --jobs NParallel jobs (default: logical CPUs).
--no-compile-commandsDo not link compile_commands.json.
--configure-onlyStop after configure.

jig run

jig run [TARGET] [--profile NAME] [--release] -- [ARGS...]. Build and run an executable.

jig test

jig test [FILTER] [--profile NAME] [-- CTEST_ARGS...]. Build and run tests. Exit 8 on failure.

jig fmt

jig fmt [--check] [PATHS...]. Format with the pinned clang-format.

jig clean

jig clean [--profile NAME] [--env] [--all].

jig doctor

jig doctor [--online] [--features] [--fix] [--strict] [--report] [--json].

jig cache

SubcommandNotes
dirPrint JIG_HOME.
sizeSizes by area.
prune [--apply] [--keep-days N]Dry run by default.
clean --downloadsRemove the download cache.

jig self

SubcommandNotes
update [--check] [--version X]Verified update.
verifyCheck this binary against the signed release data.
rollbackRestore the previous version.
wherePrint the path of the running binary.

jig completions SHELL

bash, zsh, fish, powershell, elvish.

jig version

Version, commit, build date, index format, supported manifest and lock versions.

Reserved (v0.2)

jig add, jig remove, jig tree, jig search, jig check.

Troubleshooting

Start with:

$ jig doctor
$ jig <failing command> -vv
$ jig <failing command> --explain

Find your symptom

SymptomLikely causeFix
DJ1001 No jig.toml foundYou are outside a project.cd into it, or jig init.
DJ1003 Unknown keyTypo in jig.toml.Use the suggested key.
DJ1103 jig.lock is staleManifest changed under --locked.jig lock, commit the lock.
DJ2101 No toolchain satisfies …Version not in the index for this host.jig toolchain available.
DJ2102 … accepts up to c++20Compiler too old for the standard.Newer compiler or lower std.
DJ3201 Visual Studio Build Tools not foundWindows needs the runtime and SDK.Install "Desktop development with C++".
DJ3202 macOS SDK not foundNo command line tools.xcode-select --install.
DJ3203 host requirement not metOlder glibc than the toolchain needs.Use an older toolchain or newer host.
DJ5001 offlineNeeded item not cached.Run once online or use a mirror.
DJ5101 / DJ5102Signature or hash failed.Do not bypass. Retry; if it persists, report it.
DJ4002 build failedCompile error.Fix the first failing command shown.
command not found: gcc inside jig shellThe environment hides tools it does not pin.Use c++/clang++, or vendor = "system".
Editor shows wrong includesNot using compile_commands.json.Run jig build once; reload the editor.
CI fails with a stale lockSomeone changed the manifest without relocking.jig lock locally and commit.
Build differs between two machinesDifferent host libraries (H1).Compare jig doctor --report from both.
A leaked variable changes the buildinherit = "all" or a variable not in the drop list.inherit = "none"; see [Environments](environments.md).

An install was interrupted

$ jig doctor --fix

removes incomplete store directories after listing them. Installs are atomic, so an interrupted one never becomes usable.

Reset

GoalCommand
Rebuild the environmentjig sync --reinstall
Remove build outputjig clean
Remove build output and environmentjig clean --env
Free store space (dry run first)jig cache prune, then --apply

Report a problem

$ jig doctor --report

writes jig-report-&lt;time&gt;.txt (versions, doctor output, manifest with [env] set values redacted, lock, recent log, names of leaked variables). Read it, then attach it to an issue. jig never uploads it.

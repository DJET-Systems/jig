Environment variables

Read by jig

VariableEquivalent flag / keyMeaning
JIG_HOME--home, store.homeUser data directory (store, cache, index, logs).
JIG_CONFIG_DIRDirectory holding config.toml.
JIG_MANIFEST--manifest-pathPath to jig.toml.
JIG_VERBOSE-v ...1 to 3.
JIG_QUIET-q ...1 to 2.
JIG_TERSE--terse1 enables.
JIG_JSON--json1 enables.
JIG_COLOR--colorauto, always, never.
NO_COLOR--color neverAny non-empty value disables colour.
JIG_OFFLINE--offline1 enables.
JIG_LOCKED--locked1 enables.
JIG_FROZEN--frozen1 enables.
JIG_YES-y1 enables.
JIG_NO_INTERACTIVE--no-interactive1 enables.
JIG_INDEX_URLnetwork.index-urlIndex base URL. The signature is still verified.
JIG_MIRRORnetwork.mirrorDirectory or URL that mirrors the index and archives.
HTTPS_PROXY, HTTP_PROXY, NO_PROXYnetwork.proxyStandard proxy variables.
SSL_CERT_FILE, SSL_CERT_DIRAlternative CA bundle.
SHELL, ComSpec--shellUsed by jig shell.
JIG_UPDATE_GOLDENTests only: rewrite golden files.

Precedence: flag, then variable, then jig.toml, then config.toml, then default.

Set by jig inside the environment

VariableValue
JIG_ENVAbsolute path to .jig/env.
JIG_PROJECTAbsolute path to the project root.
PATH.jig/env/bin first.
CC, CXX, ARShims inside .jig/env/bin.
CMAKE_GENERATORNinja.
CMAKE_TOOLCHAIN_FILE.jig/env/toolchain.cmake.
CMAKE_EXPORT_COMPILE_COMMANDSON.
SDKROOTmacOS SDK path (macOS only).
LIB, INCLUDE, LIBPATH, ...Visual Studio developer environment (Windows, when needed).

Removed by jig under [env] inherit = "none" or "minimal"

CC, CXX, CFLAGS, CXXFLAGS, CPPFLAGS, LDFLAGS, CPATH, C_INCLUDE_PATH, CPLUS_INCLUDE_PATH, LIBRARY_PATH, LD_LIBRARY_PATH, DYLD_LIBRARY_PATH, CMAKE_PREFIX_PATH, PKG_CONFIG_PATH.

jig doctor lists the names (never the values) of any that were present and dropped.
